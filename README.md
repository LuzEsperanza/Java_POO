# 📚 Estudos de Programação Orientada a Objetos (POO) em Java

Este repositório contém meus estudos sobre **Programação Orientada a Objetos (POO)** utilizando a linguagem Java.  
O objetivo é praticar os principais conceitos e melhorar minhas habilidades em desenvolvimento.

---

## 🧠 Conteúdos abordados

- Classes não executávei
- Objetos  
- Atributos e Métodos  
- Encapsulamento
- Modelagem Orientada a Objetos 
- Herança  
- Polimorfismo  
- Abstração
  
## 🎯 Objetivo

Desenvolver uma base sólida em Programação Orientada a Objetos, preparando para projetos maiores e oportunidades na área de tecnologia.
